# FoodApp UI - Mobile Design in Figma

High-fidelity mobile UI prototype for a Food Delivery Application.

## Problem
Users often struggle with cluttered food apps and confusing checkout flows. 

## Solution
Designed a clean, fast, and user-friendly mobile interface focusing on 3 core flows:
1. Discover → Browse restaurants and menus
2. Order → Add to cart and checkout in < 3 steps  
3. Track → Live order status updates

## Design Process
1. **Research**: Analyzed top food apps like Foodpanda, UberEats
2. **Wireframing**: Low-fi screens in Figma
3. **UI Design**: Component-based design system with Auto Layout
4. **Prototyping**: Clickable flow for testing

## Tech & Tools
`Figma` `Auto Layout` `Components` `Dev Mode` `Prototyping`
